# 2026-10-28

## Verboo Code (code.verboo.ai) 订阅调研

泽军在对比 AI 编程工具订阅，主要用 deepseek-v4.1-flash。查了 Verboo Code 定价。

**订阅档位（USD 口径，官网首页 fallback 价格）**
- Lite $20/月：有限额度，weekly allowance（具体数值官网未公布），10 个模型，8 并发
- Pro $69/月：无限 token，4 个模型（含 DeepSeek V4.1 Flash 82.8 tok/s），40 req/min，2 并发
- Max $129/月：无限 token，8 个模型
- Ultra $269/月：无限 token，9 个模型
- 巴西本地价更低：Pro = R$249/月 ≈ $45（地区定价差异大，中国用户大概率按 USD 计）

**按量 API（prepaid，无月费）**
- deepseek-v4.1-flash：input $0.14/1M，cached $0.006/1M，output $0.22/1M，1M ctx，ZDR 标记

**核心结论**
- "无限 token" 无额度上限，真实天花板是速率：2 并发 × 82 tok/s ≈ 164 tok/s，24h 跑满 ≈ 4.25 亿 output/月
- 盈亏平衡点：按 agent 场景（输入:输出=10:1，80% 缓存命中）算，每 1M output 综合成本 ≈ $0.548 → $69/月 ≈ 1.26 亿 output token。低于这个量，按量 API 更划算
- 轻度/中度使用（每天 1-4 小时）按量约 $8-22/月，远低于 $69

**风险点**
- 服务器全在巴西，国内延迟高
- 官网卡片现在标 "No free trial"，但第三方站（ntorga、withai.top）仍说 Lite 以上送 1000 万 token —— 说法矛盾
- ZDR 仅按模型标记，整体未经验证
- 席位池营销（Pro 250 席，剩 153）
