# 通知策略

MemPilot 会因为哪些事件、通过什么渠道、以什么频率打扰你——本文是唯一权威说明（v0.11.0 起的行为，代码与文档同步维护）。

## 渠道与分级

| 渠道 | 用途 | 频率约束 |
|---|---|---|
| **托盘气球** | 需要你知道但不必立刻处理的事 | 每类标题 **30 分钟冷却** |
| **主页横幅** | 当前有告急情况（内存/提交） | 常驻直到你处理或被新告警替换 |
| **非模态确认卡** | 需要你决策的事（L3 关闭闲置后台） | **30 分钟冷却**；用户不在场自动放弃并记日志 |
| **状态栏动作反馈** | 你操作的结果 | 保留 60 秒（刷新文案不会覆盖它） |
| **决策日志** | 一切自动决定的完整记录 | 不打扰，事后查 |

**模态 MessageBox 只用于破坏性确认**（L4 强制结束、腾内存计划执行、出厂重置等），
信息类通知一律不走模态框。

## 托盘气球白名单（仅这四类会发）

| 事件 | 说明 |
|---|---|
| 内存/提交告急 | 引擎 Alert 触达；冷却 30 分钟 |
| 租约侵蚀告警 | 占用期可用跌破授予下限 |
| 模式切换 | 自动切换或手动切换时 |
| 用户主动长操作完成 | 腾内存执行完毕（你主动发起的，切走了也该知道结果） |
| 垃圾进程建议（v0.15.0） | 整天未使用的垃圾进程——**每天最多 1 次**，引擎侧保证；v0.17 起只在**本地 19 点后**评估（午夜评估会让所有进程都算"今天未使用"），托盘模式未交付则自动重试、不消耗提示冷却；设置页可「立即检查」手动触发 |

**不发**的：设置已保存、一键回收完成（结果在状态栏 60 秒 + 审计页）、周期性提示
（GrowthWatch/HabitHint/CommitWatch 只进决策日志）。

## 决策日志"只记录"的事件

这些事件只写 `decisions.json`，不主动打扰——它们是提示不是告急：

- `GrowthWatch`：后台进程工作集增长超 800MB（每 PID 48 小时最多 1 条）
- `HabitHint`：历史画像显示某时段内存常态偏低（每时段每天 1 条；同时更新主页"时段画像"卡）
- `SceneShadow`：影子模式判定"如果自动切换会切到哪"
- `PromoteRule` / `RuleAudit`：规则晋升建议与每周规则体检（建议项会出现在主页"待处理"卡）

## 总开关

设置 →「重要提示触达」：关闭后托盘气球与主页横幅全部静默，一切照常写入决策日志——
"只观察、不打扰"模式。
