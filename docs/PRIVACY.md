# 数据与隐私说明

MemPilot 读取全系统的进程信息——这份说明告诉你它**记了什么、存在哪、保留多久、什么会离开你的电脑**。

## 记录什么

| 数据 | 内容 | 用途 |
|---|---|---|
| 进程快照 | 进程名、PID、内存指标（工作集/私有/提交）、分类与用途、窗口有无、CPU | 进程页展示、未使用判定 |
| 系统采样 | 总量/可用/提交水位、进程线程总数、当前模式、当期内存 Top10 | 历史页曲线、习惯画像 |
| 显存采样 | 适配器与逐进程显存占用（PDH） | 显存曲线、AI 会话识别 |
| 程序清单 | 注册表卸载项、开始菜单快捷方式、常见安装根的 exe 路径索引 | "所属程序"列、分类证据 |
| 决策/审计日志 | 每个自动动作的原因与前后实测值 | 可解释性、事后追查 |
| 行为画像 | 按进程名累计的在场/空闲/音频次数 | 垃圾驻留分、规则卫生报告 |
| 反馈 | 你右键做的标记（保留/可清理/用途） | 分类修正 |
| 用户配置 | 阈值、名单、模式档案、**API 密钥（DPAPI 加密）** | 设置 |

## 存在哪

全部在本机 `%APPDATA%\MemPilot\`（单文件 ~8 MB 量级，含 30 天采样）。列出它：主页首屏说明卡 →「打开数据目录」。

## 保留多久

- 历史/显存采样：**30 天**（`UsageRetentionDays` 可调），过期自动清理
- 决策日志：5,000 条环形（按 Kind 分桶，重要记录不被噪声挤掉）
- 审计日志：2,000 条
- 行为画像/程序清单/反馈：跟随配置，随`/reset`出厂重置一并清空

## 什么会离开你的电脑

**默认：什么都不出。** 程序没有任何遥测、不上报任何统计、没有更新检查请求。

唯一可能产生网络请求的功能是**联网查询**（可选，默认关闭且未配置端点时完全不发）：
你自定义的端点或 VirusTotal，查询内容仅限**进程文件路径的哈希**，结果缓存 7 天。
不配置 = 零网络行为（租约 API 只监听本机 127.0.0.1，不是出站请求）。

## 怎么全部清掉

1. 设置 → `/reset` 出厂重置（清配置与数据）
2. 或直接删除 `%APPDATA%\MemPilot\` 整个目录（先退出程序）

## 开源可审计

上述行为全部可由源码验证：采样写入 `UsageRecorder`/`GpuRecorder`，日志写入
`DecisionLog`/`AuditLogger`，唯一出站点在 `OnlineLookupService.SendAsync`（发送前有
https/localhost 检查）。仓库内 `docs/HISTORY-AUDIT.md` 是 git 历史本身的隐私审计报告。
